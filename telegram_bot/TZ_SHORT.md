# ТЗ для Claude Code: Telegram Shop Bot

## Что нужно сделать

Разработать современный Telegram-магазин с базой данных SQLite, админ-панелью и полным функционалом электронной коммерции.

## Технологии

- Python 3.11+
- python-telegram-bot 21.0+
- SQLAlchemy 2.0 + aiosqlite
- Деплой: Railway.app

## База данных (SQLAlchemy модели)

### 10 основных таблиц:

1. **users** - пользователи (telegram_id, username, phone, created_at)
2. **categories** - категории товаров (name, emoji, position, is_active)
3. **products** - товары (category_id, name, description, price, photo_url, stock_quantity, is_available)
4. **orders** - заказы (user_id, status, total_price, total_price_usdt, delivery_type, pickup_point_id, pickup_code, phone, payment_method, payment_status, payment_txid)
5. **order_items** - состав заказов (order_id, product_id, quantity, price)
6. **admins** - администраторы (telegram_id, role)
7. **settings** - настройки магазина (key, value)
8. **pickup_points** - точки выдачи (name, address, latitude, longitude, working_hours, is_active)
9. **payment_wallets** - кошельки USDT (currency, address, is_active)
10. **payment_confirmations** - подтверждения оплаты (order_id, admin_id, txid, confirmed_at)

## Функционал пользователя

### Главное меню:
- 🛒 Каталог (категории → товары → карточка товара)
- 🧺 Корзина (+ добавление, - удаление, подсчёт суммы)
- 📦 Мои заказы (история с фильтром по статусу)
- ℹ️ О магазине

### Оформление заказа:
1. Выбор: Самовывоз / Доставка
2. Телефон (валидация)
3. Комментарий (опционально)
4. Выбор оплаты: **💎 USDT TRC20** / 💵 Наличные
5. **Если USDT:**
   - Показать адрес кошелька + QR-код
   - Показать сумму в USDT
   - Таймер 30 минут
   - Кнопка "✅ Я оплатил"
   - Админ проверяет и подтверждает
   - **После подтверждения → клиент получает:**
     - 📍 Координаты точки выдачи (Telegram Location)
     - 📝 Адрес и время работы
     - 📦 Код для получения (#A1234)
6. Подтверждение

### Уведомления:
- При создании заказа (инструкция по оплате)
- Админу: "Клиент сообщил об оплате" (с кнопками проверки)
- При подтверждении оплаты (координаты + код выдачи)
- При готовности к выдаче

## Функционал админа

### Главное меню админки:
- 📋 Заказы (список → детали → изменить статус)
- 💰 **Платежи (ожидают подтверждения USDT)**
- 📦 Товары (CRUD: добавить/редактировать/удалить)
- 📁 Категории (CRUD)
- 📍 **Точки выдачи** (CRUD: название, адрес, координаты, время работы)
- 💎 **Кошельки USDT** (добавить/удалить TRC20 адреса)
- 👥 Пользователи (список, блокировка)
- 📊 Статистика (выручка, топ товаров, графики)
- 💬 Рассылка (текст/фото всем пользователям)

### Управление товарами через диалог:
1. Выбрать категорию
2. Ввести название
3. Ввести описание
4. Ввести цену
5. Загрузить фото (опционально)
6. Указать остаток на складе

### Уведомления админам:
- Новый заказ (мгновенно с кнопками Принять/Отменить)
- **Клиент сообщил об оплате USDT** (кнопка "🔍 Проверить" → tronscan.org, кнопка "✅ Подтвердить")
- Низкий остаток товара

## Процесс оплаты USDT TRC20

### Создание заказа:
1. Клиент оформляет заказ
2. Выбирает способ оплаты: **💎 USDT TRC20**
3. Система:
   - Конвертирует сумму в USDT (по курсу из настроек)
   - Показывает адрес кошелька для оплаты
   - Генерирует QR-код
   - Запускает таймер (30 минут)
4. Клиент видит:
   ```
   💎 Оплата USDT TRC20
   
   Адрес кошелька:
   TXxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   
   [QR-код]
   
   Сумма: 15.50 USDT
   
   ⏱ Осталось времени: 29:45
   
   [✅ Я оплатил]  [❌ Отменить заказ]
   ```

### Подтверждение оплаты:
1. Клиент нажимает "✅ Я оплатил"
2. Админы получают уведомление:
   ```
   💰 ТРЕБУЕТСЯ ПОДТВЕРЖДЕНИЕ ОПЛАТЫ
   
   Заказ #123
   Клиент: @username
   Сумма: 15.50 USDT
   Кошелёк: TXxxx...xxx
   
   [🔍 Проверить в Tronscan]
   [✅ Подтвердить оплату]
   [❌ Отклонить]
   ```
3. Админ нажимает "🔍 Проверить в Tronscan"
   - Открывается `https://tronscan.org/#/address/{wallet}`
   - Админ проверяет входящие транзакции
4. Админ нажимает "✅ Подтвердить оплату"
   - Вводит TXID транзакции (опционально)
   - Подтверждает

### После подтверждения:
Клиент получает:
```
✅ ОПЛАТА ПОДТВЕРЖДЕНА!

📦 Ваш заказ #123 оплачен

📍 Точка выдачи:
ТЦ "Центральный", 2 этаж, вход Б

🕐 Время работы: Пн-Вс 10:00-22:00

📦 Код для получения: #A1234

[🗺 Показать на карте]
```

+ Отправляется Telegram Location с координатами

## Важные детали

1. **Async/await** везде
2. **FSM (ConversationHandler)** для многошаговых диалогов
3. **Декоратор admin_only** для защиты админских функций
4. **Пагинация** для длинных списков (товары, заказы)
5. **HTML-разметка** для красивых сообщений
6. **Логирование** всех действий

## Примеры кода

### Декоратор для админов:
```python
def admin_only(func):
    async def wrapper(update, context):
        user_id = update.effective_user.id
        if not await is_admin(user_id):
            await update.message.reply_text("❌ Нет доступа!")
            return
        return await func(update, context)
    return wrapper
```

### CRUD пример:
```python
async def create_order(user_id: int, items: list, address: str, phone: str):
    async with AsyncSession() as session:
        order = Order(user_id=user_id, status='new', ...)
        session.add(order)
        await session.commit()
        return order.id
```

## Статусы заказов

- `new` - 🔔 Новый
- `confirmed` - ✅ Подтверждён
- `preparing` - 👨‍🍳 Готовится
- `delivering` - 🚚 В доставке
- `completed` - ✨ Выполнен
- `cancelled` - ❌ Отменён
