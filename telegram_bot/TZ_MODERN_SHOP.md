# ТЗ: Современный Telegram Shop Bot

## 🎯 Общая концепция

Разработать полнофункциональный интернет-магазин в Telegram с современным стеком технологий, базой данных, админ-панелью и платежной интеграцией.

---

## 📋 Технический стек

### Backend
- **Python 3.11+**
- **python-telegram-bot 21.0+** (последняя версия)
- **SQLAlchemy 2.0** для работы с БД
- **aiosqlite** для асинхронной работы с SQLite
- **Alembic** для миграций БД (опционально)

### База данных
- **SQLite** для разработки
- Возможность переключения на **PostgreSQL** для production (Railway Postgres)

### Деплой
- **Railway.app** или **Fly.io**
- **Docker** support (опционально)

---

## 🗄️ Структура базы данных

### Таблицы

#### 1. `users`
```sql
- id (INTEGER, PRIMARY KEY)
- telegram_id (BIGINT, UNIQUE, NOT NULL)
- username (VARCHAR, NULLABLE)
- first_name (VARCHAR)
- phone (VARCHAR, NULLABLE)
- created_at (TIMESTAMP)
- is_blocked (BOOLEAN, DEFAULT FALSE)
```

#### 2. `categories`
```sql
- id (INTEGER, PRIMARY KEY)
- name (VARCHAR, NOT NULL)
- emoji (VARCHAR)
- description (TEXT, NULLABLE)
- is_active (BOOLEAN, DEFAULT TRUE)
- position (INTEGER, DEFAULT 0)  # для сортировки
- created_at (TIMESTAMP)
```

#### 3. `products`
```sql
- id (INTEGER, PRIMARY KEY)
- category_id (INTEGER, FOREIGN KEY -> categories.id)
- name (VARCHAR, NOT NULL)
- description (TEXT)
- price (DECIMAL, NOT NULL)
- photo_url (VARCHAR, NULLABLE)
- is_available (BOOLEAN, DEFAULT TRUE)
- stock_quantity (INTEGER, DEFAULT 0)  # остатки на складе
- position (INTEGER, DEFAULT 0)
- created_at (TIMESTAMP)
- updated_at (TIMESTAMP)
```

#### 4. `orders`
```sql
- id (INTEGER, PRIMARY KEY)
- user_id (INTEGER, FOREIGN KEY -> users.id)
- status (VARCHAR)  # new, awaiting_payment, paid, ready, completed, cancelled
- total_price (DECIMAL, NOT NULL)
- total_price_usdt (DECIMAL, NULLABLE)  # сумма в USDT
- delivery_type (VARCHAR)  # pickup, delivery
- delivery_address (TEXT, NULLABLE)  # только для delivery
- pickup_point_id (INTEGER, FOREIGN KEY -> pickup_points.id, NULLABLE)
- pickup_code (VARCHAR, NULLABLE)  # код для получения товара
- phone (VARCHAR)
- comment (TEXT, NULLABLE)
- payment_method (VARCHAR)  # usdt_trc20, cash
- payment_status (VARCHAR)  # pending, paid, refunded
- payment_address (VARCHAR, NULLABLE)  # адрес кошелька куда переведено
- payment_txid (VARCHAR, NULLABLE)  # ID транзакции в блокчейне
- created_at (TIMESTAMP)
- paid_at (TIMESTAMP, NULLABLE)
- updated_at (TIMESTAMP)
```

#### 5. `order_items`
```sql
- id (INTEGER, PRIMARY KEY)
- order_id (INTEGER, FOREIGN KEY -> orders.id)
- product_id (INTEGER, FOREIGN KEY -> products.id)
- quantity (INTEGER, NOT NULL)
- price (DECIMAL, NOT NULL)  # цена на момент заказа
- product_name (VARCHAR)  # название на момент заказа
```

#### 6. `admins`
```sql
- id (INTEGER, PRIMARY KEY)
- telegram_id (BIGINT, UNIQUE, NOT NULL)
- username (VARCHAR)
- role (VARCHAR)  # superadmin, admin, moderator
- created_at (TIMESTAMP)
```

#### 7. `settings`
```sql
- id (INTEGER, PRIMARY KEY)
- key (VARCHAR, UNIQUE, NOT NULL)
- value (TEXT)
- description (TEXT, NULLABLE)
```

#### 8. `pickup_points`
```sql
- id (INTEGER, PRIMARY KEY)
- name (VARCHAR, NOT NULL)  # название точки
- address (TEXT, NOT NULL)
- latitude (DECIMAL, NOT NULL)  # широта
- longitude (DECIMAL, NOT NULL)  # долгота
- working_hours (VARCHAR)  # например: "Пн-Пт 9:00-21:00"
- is_active (BOOLEAN, DEFAULT TRUE)
- created_at (TIMESTAMP)
```

#### 9. `payment_wallets`
```sql
- id (INTEGER, PRIMARY KEY)
- currency (VARCHAR, NOT NULL)  # usdt_trc20
- address (VARCHAR, NOT NULL, UNIQUE)  # адрес кошелька
- is_active (BOOLEAN, DEFAULT TRUE)
- created_at (TIMESTAMP)
- last_used_at (TIMESTAMP, NULLABLE)
```

#### 10. `payment_confirmations`
```sql
- id (INTEGER, PRIMARY KEY)
- order_id (INTEGER, FOREIGN KEY -> orders.id)
- admin_id (INTEGER, FOREIGN KEY -> admins.id)
- confirmed_at (TIMESTAMP)
- txid (VARCHAR, NULLABLE)  # ID транзакции
- notes (TEXT, NULLABLE)  # комментарий админа
```

## 🎨 Функционал для покупателей

### 1. Главное меню
- 🛒 Каталог товаров
- 🧺 Моя корзина (с счетчиком количества товаров)
- 📦 Мои заказы
- ℹ️ О магазине / Контакты
- ⚙️ Настройки

### 2. Каталог товаров
- Просмотр категорий с эмодзи
- Фильтрация по категориям
- Пагинация товаров (по 5-10 на страницу)
- Карточка товара с:
  - Фото (или placeholder если нет)
  - Название
  - Описание
  - Цена
  - Наличие на складе
  - Кнопки: ➖ [Количество] ➕ | 🛒 В корзину

### 3. Корзина
- Список товаров с:
  - Название
  - Количество
  - Цена за единицу
  - Сумма
  - Кнопка удаления
- Итоговая сумма
- Кнопка "Очистить корзину"
- Кнопка "Оформить заказ"

### 4. Оформление заказа
- Ввод адреса доставки **ИЛИ** выбор самовывоза
- Ввод номера телефона (с валидацией)
- Комментарий к заказу (опционально)
- Выбор способа оплаты:
  - 💎 **USDT TRC20** (основной метод)
  - 💵 Наличными при получении (опционально)
- **Процесс оплаты через USDT TRC20:**
  1. Система генерирует уникальный номер заказа
  2. Показывается адрес кошелька для оплаты (TRC20)
  3. Показывается сумма к оплате в USDT
  4. Показывается QR-код для быстрой оплаты
  5. Таймер ожидания оплаты (15-30 минут)
  6. Клиент переводит USDT на указанный адрес
  7. Кнопка "✅ Я оплатил" для уведомления
  8. Админ получает уведомление о возможной оплате
  9. Админ проверяет транзакцию вручную (пока без API)
  10. Админ подтверждает оплату
  11. **После подтверждения клиент получает:**
      - ✅ Уведомление об успешной оплате
      - 📍 **Координаты точки выдачи** (широта, долгота)
      - 🗺 **Интерактивная карта** с меткой (Telegram Location)
      - 📝 **Адрес точки выдачи** текстом
      - 🕐 **Время работы точки выдачи**
      - 📦 **Код для получения товара** (например: #A1234)
- Подтверждение заказа с итоговой информацией

### 5. Мои заказы
- История всех заказов
- Статусы заказов с эмодзи:
  - 🔔 Новый
  - ✅ Подтверждён
  - 👨‍🍳 Готовится
  - 🚚 В доставке
  - ✨ Выполнен
  - ❌ Отменён
- Детали каждого заказа
- Кнопка "Отменить заказ" (только для новых)

### 6. Уведомления клиента
- При оформлении заказа
- При изменении статуса заказа
- При отмене заказа

## 👨‍💼 Функционал админ-панели

### 1. Главное меню админки
- 📋 Заказы
- 💰 **Платежи (ожидают подтверждения)**
- 📦 Товары
- 📁 Категории
- 📍 **Точки выдачи**
- 💎 **Кошельки USDT**
- 👥 Пользователи
- 📊 Статистика
- 💬 Рассылка
- ⚙️ Настройки

### 2. Управление заказами
- Список всех заказов с фильтрацией:
  - Все
  - Новые
  - Ожидают оплаты
  - Оплачены
  - Готовы к выдаче
  - Выполненные
  - Отменённые
- Детали заказа:
  - Информация о клиенте
  - Состав заказа
  - Адрес или точка выдачи
  - **Статус оплаты:**
    - Если USDT: адрес кошелька, сумма, ссылка на проверку транзакции
    - Кнопка "🔍 Проверить в блокчейне" (открывает tronscan.org)
  - Статус и история изменений
- Действия:
  - **Подтвердить оплату** (для заказов со статусом awaiting_payment)
  - Изменить статус → ready (готов к выдаче)
  - Изменить статус → completed (выдан)
  - Отменить заказ
  - Связаться с клиентом (кнопка для копирования @username)

### 2.1. Управление платежами (новый раздел)
- **Список заказов ожидающих подтверждения оплаты:**
  - Номер заказа
  - Клиент
  - Сумма в USDT
  - Адрес кошелька
  - Время создания
  - Таймер (сколько осталось до истечения)
  
- **Детали платежа:**
  - Вся информация о заказе
  - Адрес кошелька для оплаты
  - Сумма в USDT
  - Кнопка "🔍 Проверить транзакцию" → открывает:
    - `https://tronscan.org/#/address/{wallet_address}`
  - Поле для ввода TXID (ID транзакции)
  - Кнопки:
    - ✅ **Подтвердить оплату** (запросить TXID)
    - ❌ **Отклонить / Оплата не поступила**
    - ⏱ **Продлить время ожидания**

- **После подтверждения:**
  - Статус заказа → paid
  - Клиенту отправляется:
    - ✅ Уведомление об оплате
    - 📍 Координаты точки выдачи
    - 🗺 Карта (Telegram Location)
    - 📦 Код для получения
    - 🕐 Время работы

### 2.2. Управление точками выдачи
- **Список точек выдачи:**
  - Название
  - Адрес
  - Координаты
  - Режим работы
  - Активна/Неактивна
  - Количество активных заказов

- **Добавление точки:**
  1. Ввести название
  2. Ввести адрес
  3. Отправить геолокацию (Telegram Location) ИЛИ ввести координаты вручную
  4. Ввести режим работы
  5. Сохранить

- **Редактирование точки:**
  - Изменить название
  - Изменить адрес
  - Изменить координаты
  - Изменить режим работы
  - Вкл/Выкл точку

- **Удаление точки:**
  - Только если нет активных заказов

### 2.3. Управление кошельками USDT
- **Список кошельков:**
  - Адрес кошелька TRC20
  - Активен/Неактивен
  - Последнее использование
  - Количество транзакций

- **Добавление кошелька:**
  1. Ввести адрес TRC20
  2. Валидация адреса (начинается с T, длина 34 символа)
  3. Сохранить

- **Редактирование:**
  - Вкл/Выкл кошелек

- **Примечание:**
  - Система использует активные кошельки по очереди
  - Можно настроить один основной кошелек

### 3. Управление товарами
- Список всех товаров с пагинацией
- Поиск товара по названию
- Фильтр по категориям
- Действия:
  - ➕ Добавить товар (пошаговый диалог):
    1. Выбрать категорию
    2. Ввести название
    3. Ввести описание
    4. Ввести цену
    5. Загрузить фото (опционально)
    6. Указать количество на складе
  - ✏️ Редактировать товар:
    - Изменить название
    - Изменить описание
    - Изменить цену
    - Изменить фото
    - Изменить остаток
    - Вкл/выкл доступность
  - 🗑 Удалить товар (с подтверждением)
  - 📊 Статистика по товару

### 4. Управление категориями
- Список категорий
- ➕ Добавить категорию:
  - Название
  - Эмодзи
  - Описание
- ✏️ Редактировать категорию
- 🗑 Удалить категорию (если нет товаров)
- ⬆️⬇️ Изменить порядок (position)

### 5. Управление пользователями
- Список всех пользователей
- Фильтры:
  - Все
  - Активные
  - Заблокированные
- Информация о пользователе:
  - Telegram ID
  - Username
  - Дата регистрации
  - Количество заказов
  - Общая сумма покупок
- Действия:
  - 🚫 Заблокировать/разблокировать
  - 📧 Отправить сообщение

### 6. Статистика
- **Общая:**
  - Всего заказов
  - Общая выручка
  - Средний чек
  - Всего пользователей
  - Новых пользователей за сегодня/неделю/месяц
  
- **По товарам:**
  - Топ-10 самых продаваемых
  - Товары с низким остатком (< 5 шт.)
  
- **По датам:**
  - График заказов за неделю/месяц
  - График выручки за неделю/месяц

- **Экспорт:**
  - Скачать отчет в CSV

### 7. Рассылка
- Отправка сообщений всем пользователям
- Предпросмотр сообщения
- Поддержка:
  - Текст
  - Фото + текст
  - Кнопки (опционально)
- Статистика рассылки (сколько доставлено)

### 8. Настройки
- **Общие:**
  - Название магазина
  - Описание
  - Контактный телефон
  - Время работы
  - Минимальная сумма заказа
  
- **Доставка:**
  - Стоимость доставки
  - Бесплатная доставка от (сумма)
  - Зоны доставки
  
- **Уведомления:**
  - Telegram ID для уведомлений админов
  - Шаблоны уведомлений

## 🔔 Система уведомлений

### Для админов
- **Новый заказ** (мгновенно всем админам):
  - Состав заказа
  - Клиент
  - Способ оплаты
  - Если USDT: ожидает оплату
  
- **Клиент сообщил об оплате** (кнопка "Я оплатил"):
  - Номер заказа
  - Сумма в USDT
  - Адрес кошелька
  - Кнопка "🔍 Проверить" → tronscan.org
  - Кнопка "✅ Подтвердить оплату"
  - Кнопка "❌ Отклонить"
  
- **Истекает время оплаты** (за 5 минут до истечения)
- Новый пользователь (опционально)
- Низкий остаток товара

### Для клиентов
- **Заказ создан:**
  - Если USDT: адрес кошелька, QR-код, сумма, инструкция
  - Если наличные: информация о доставке
  
- **Напоминание об оплате** (через 10 минут если не оплатил)

- **Оплата подтверждена:**
  - ✅ Оплата получена
  - 📍 **Координаты точки выдачи** (Location)
  - 📝 Адрес текстом
  - 🕐 Время работы
  - 📦 Код для получения: **#A1234**
  - Инструкция: "Покажите код оператору"
  
- **Заказ готов к выдаче:**
  - Уведомление что можно забрать
  - Повтор координат и кода
  
- **Заказ выдан:**
  - Благодарность за покупку
  - Просьба оставить отзыв (опционально)
  
- **Заказ отменён:**
  - Причина (если указана)
  - Если была оплата: информация о возврате

## 🔐 Безопасность

1. **Переменные окружения:**
   - `BOT_TOKEN` - токен бота
   - `DATABASE_URL` - URL БД
   - `ADMIN_IDS` - список ID админов через запятую
   - `USDT_WALLET_ADDRESS` - основной кошелёк USDT TRC20 для приёма платежей
   - `USDT_RATE` - курс USDT к рублю (обновляется вручную или через API)
   - `PAYMENT_TIMEOUT_MINUTES` - таймаут ожидания оплаты (по умолчанию 30)

2. **Валидация:**
   - Проверка прав доступа для админ-функций
   - Валидация номера телефона
   - Проверка количества товара на складе перед добавлением в заказ
   - **Валидация адреса USDT кошелька** (формат TRC20)
   - **Проверка минимальной суммы заказа**

3. **Защита от спама:**
   - Rate limiting для команд
   - Антифлуд для рассылок
   - **Защита от повторной оплаты** (один заказ = одна оплата)

4. **Безопасность платежей:**
   - Генерация уникальных кодов выдачи
   - Логирование всех подтверждений оплаты
   - История изменения статусов заказа
