# 🛒 Telegram Shop Bot с Админ-Панелью

Полноценный интернет-магазин в Telegram с корзиной, каталогом, оформлением заказов и **мощной админ-панелью**.

## ✨ Возможности

### Для покупателей:
- 🛒 Каталог товаров с категориями
- 📸 Карточки товаров с фото
- 🧺 Корзина покупок
- ➕➖ Добавление/удаление товаров
- 📝 Оформление заказа с адресом доставки
- 💰 Автоматический подсчет суммы
- 🔔 Уведомления о статусе заказа

### Для администраторов:
- 👨‍💼 **Админ-панель** с полным контролем
- 📋 **Управление заказами**: просмотр, принятие, отмена
- 📦 **Управление товарами**: добавление, редактирование, удаление
- 📊 **Статистика**: выручка, топ продаж, средний чек
- 📁 Просмотр категорий
- 🔔 Мгновенные уведомления о новых заказах
- 🎯 Автоматическая отправка статусов клиентам

## 🚀 Быстрый старт

### 1. Получите токен бота

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен

### 2. Узнайте свой Telegram ID

1. Найдите [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте `/start`
3. Скопируйте ваш ID (например: `123456789`)

### 3. Настройте админов

Откройте `bot.py` и на **строке 28** замените ID на свои:

```python
ADMINS = [123456789, 987654321]  # Вставьте СВОИ ID!
```

### 4. Локальный запуск

```bash
# Установите зависимости
pip install -r requirements.txt

# Вставьте токен в bot.py (строка 25) ИЛИ используйте переменную окружения
export BOT_TOKEN="ваш_токен_здесь"

# Запустите
python bot.py
```

### 5. Деплой на Railway

1. Зарегистрируйтесь на [Railway.app](https://railway.app)
2. Создайте новый проект: **New Project** → **Deploy from GitHub repo**
3. Подключите этот репозиторий
4. Добавьте переменные окружения:
   - `BOT_TOKEN` = ваш токен от BotFather
   - `ADMIN_ID_1` = ваш Telegram ID
   - `ADMIN_ID_2` = ID второго админа (опционально)

5. **ВАЖНО!** Settings → **Replicas: 1** (не больше!)

## 👨‍💼 Как пользоваться админ-панелью

### Доступ к админке:
1. Напишите боту `/admin` или `/start`
2. Нажмите кнопку **"👨‍💼 Админ-панель"**

### Управление заказами:
- **📋 Заказы** → список всех заказов
- Клик на заказ → детали + кнопки:
  - ✅ **Принять** → клиент получит уведомление
  - ❌ **Отменить** → клиент получит уведомление об отмене

### Управление товарами:
- **📦 Товары** → меню управления
  - **➕ Добавить товар** (coming soon)
  - **📝 Редактировать товар** → выберите товар → измените цену/название/описание
  - **🗑 Удалить товар** → выберите товар → подтвердите удаление

### Статистика:
- **📊 Статистика** → 
  - Общее количество заказов
  - Общая выручка
  - Средний чек
  - Топ-5 самых продаваемых товаров

## 🐛 Решение проблем

### Ошибка "Conflict: terminated by other getUpdates"

**Причина**: Запущено несколько копий бота.

**Решение**:
1. Остановите все старые деплои на Railway
2. Убедитесь что `Replicas = 1`
3. Подождите 30 секунд
4. Перезапустите бот

### Админ-панель не появляется

1. Проверьте, что ваш ID добавлен в список `ADMINS` (строка 28)
2. Узнайте свой ID через [@userinfobot](https://t.me/userinfobot)
3. Перезапустите бота после изменения `ADMINS`

### Бот не отвечает

1. Проверьте логи Railway: **Deployments** → **View Logs**
2. Убедитесь, что токен правильный
3. Проверьте переменную `BOT_TOKEN` в Railway

### Фото товаров не загружаются

1. Убедитесь, что URL ведет на прямую ссылку на изображение
2. Используйте https:// ссылки
3. Проверьте формат: .jpg, .jpeg, .png
